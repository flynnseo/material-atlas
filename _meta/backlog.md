# 조사 대기열

형식: `- [ ] 이름 | 소재군 | 메모(어디서 봤는지, 사진 경로)`
Claude Code `/batch <소재군>` 이 위에서부터 가져가서 draft 카드로 만들고 체크한다.
`id:` 가 적힌 항목은 다른 카드가 이미 그 id로 링크하고 있으니 그대로 쓸 것.
신소재(emerging)는 여기 말고 Phase 2 레이더 흐름(material-scout → material-verifier)으로 들어온다.
