# _inbox — 메모 던지는 곳

아무렇게나 써서 여기 넣으면 된다. 형식 없음.
- `.md` / `.txt` 메모, 사진(`.jpg` `.png` `.heic`), 메모 + 사진 같은 이름(`황동선반.md` + `황동선반.jpg`)이면 한 묶음으로 처리.
- 소재 이름·별명·은어 아무거나 쓰면 Claude가 관련 카드를 찾아 붙인다.

정리: Claude Code에서 `/ingest-memo` → 관련 카드의 `## 태건 메모` 섹션에 원문 그대로 붙이고, 처리한 파일은 `_inbox/done/<날짜>/` 로 옮긴다.
`hands_on` 은 Claude가 바꾸지 않는다 — "직접 해본 정황" 이 보이면 리포트만 한다.
